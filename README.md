# 🎬 Gemini 工业级高可用双语字幕转换器

基于 **Streamlit** 前端框架与 **LangChain (Google GenAI)** 构建的智能字幕翻译工具。专门针对长视频、多条目字幕设计，具备极高稳定性的红队武器级防熔断机制。

## ✨ 核心特性

- **JSON 级原子化双向绑定**：抛弃传统“小作文”式全文本翻译，采用标准 JSON 数组传递纯文本，彻底解决大模型合并段落、断行导致的字幕错位与时间轴走样问题。
- **铁血密钥池高可用接力**：支持配置 5 个不同的 Google API Key 轮询待命。遭遇频率限制（429 Rate Limit）时自动交替接力，支持超长视频字幕挂机翻译。
- **超级防御性数据洗涤**：内置深层类型解包逻辑，完美防御和清洗 LangChain 框架偶发性返回的 `list` 块对象，保障数据链路永不断流。
- **全量 Console 级 Debug 日志**：控制台实时打印完整的输入 Prompt、大模型响应耗时、行数校验以及全量译文对照，运行状态一目了然。
- **双向多语种灵活切换**：支持中文、英文、日语、韩语等主流语言的一键下拉互译，并提供自定义语种输入扩展。
- **10秒物理充能冷却**：每轮大包（如 50 行）翻译结束后，强制进入 10 秒物理冷却计数，平稳消耗免费 Tier 额度。
